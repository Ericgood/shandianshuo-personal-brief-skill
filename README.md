# 闪电说个人信息推荐 Skill

把一段时间的闪电说转写变成可纠正的个人偏好文档，再从原作者内容中筛选每日阅读，持续去重、积累信源。

**完整理解授权范围，不抽样；整理分析副本，不删除原历史。** 使用者各自的数据、画像和推荐账留在自己的工作区。这个仓库没有任何真实用户转写、画像、密钥或个人评分。

## 发给助理的口令

把本仓库链接和下面这段发给闪电说助理或支持文件/联网工具的Agent：

> 请读取 https://github.com/Ericgood/shandianshuo-personal-brief-skill ，安装并启用其中的 shandianshuo-personal-brief Skill。首次先问我想分析多长时间；检查已有身份资料，有就请我确认是否仍准确，没有就问我主要做什么、最近在忙什么，再了解我当前想看和不想看的内容。允许当前Agent模型处理我随后选定范围的闪电说“直接说/帮我说”文字，只整理分析副本，不改原记录。完整理解后，给我偏好文档，并立即输出今天的个性化推荐，再问我后续每日运行的时间与时区，接入真实定时任务。不要把数据、画像或阅读记录上传GitHub或AIHOT；缺工具明确说明。

也可在首句直接指定90天/一年或明确历史区间，以及每日时间、时区和模型选择；已明确的答案不会重复询问。窗口越长、数据越多通常越耗时和额度；数据不足就分析实际可用范围。初次处理可能跨多轮，进度会保存，不能用摘要/抽样冒充完成。身份可以跳过，不要求姓名或雇主。

## 会得到什么

1. 冻结的私有文字批次与逐片段理解、可续跑的覆盖账。
2. `library/个人信息偏好.md`：本人背景、远中近期候选、变化、反例、负偏好、证据及用户纠正。
3. **首次分析完立即给今天的0—5条阅读**：原作者是谁、内容是什么、为什么适合你、原日期/原链接和阅读限制；偏好文档和当日报告都会展示，不只留一个明天才运行的任务。没有可靠内容时如实给零条报告。
4. 持续维护的信源与内容账：同作者多平台关联、同文章去重、同事件的新观点辨别；推荐过与读过分开。
5. 宿主提供调度能力时，创建并回查真实每日任务；以后每天完整理解新增/修改文字，更新近期需要和候选证据，每7天在同一任务里复盘稳定偏好，不每天重算一年。

## 每天跟上你，每周复盘偏好

- **稳定偏好**：谨慎调整，每周结合既有跨期理解与新证据复盘。
- **近期需要**：每天更新。今天或昨天刚说的具体需要，完整理解后就能参与当天推荐，不必先成为长期兴趣。
- **新观察候选**：先保留日期、证据和不确定性，不自动升级稳定标签；明确身份更正、喜恶或拒绝推荐立即生效。

推荐理由会解释文章与你近期需要的联系，不直接复述私密原话，也不为体现“读了昨天记录”而凑推荐。每日任务检查是否满7天并在本轮复盘，不要求再创建第二个周期任务；失败不冒充完成，漏跑不只补最近7天。已有安装需更新Skill文件和每日任务提示词，远端仓库更新不自动改写本机任务。

## 兼容条件

- 根[SKILL.md](SKILL.md)是通用入口，可按Agent自己的Skill安装方式使用；附带helper需要Node.js 20+，无第三方依赖。
- 当前数据helper支持闪电说国内新工作区的 `history/transcriptions.json`。旧布局、其他版本或海外版需提供受支持导出/路径，不能承诺所有安装版直接可用。
- 闪电说保存Skill不等于启用。新版本有产品工具时可按口令启用并回查；旧版需要在技能页启用。
- 闪电说的每日调度依赖可选官方 **Automation tasks**。缺工具时先生成任务模板并说明开启方式；Skill文件自己不会准时醒来。关闭宿主/休眠/额度不足会影响执行，当前DSH关闭后仅补最近一次错过周期。
- Agent须具备授权范围内的本地文件、执行、联网与足够模型上下文/额度；不支持这些能力时只能完成对应的部分，不能“任意聊天模型一条链接就全自动”。

## 安装者与开发者

仓库根本身就是技能目录，包含SKILL.md、references、assets和scripts。闪电说用受支持文件工具放到 `library/skills/shandianshuo-personal-brief/` 后确认启用；不要修改私有状态文件。其他宿主放入其技能目录。脚本cwd是用户工作区，脚本路径是安装目录，二者可不同。

```text
node <skill-dir>/scripts/history.mjs inventory --days 365
node <skill-dir>/scripts/history.mjs prepare --days 365
node <skill-dir>/scripts/history.mjs next RUN
node <skill-dir>/scripts/history.mjs accept RUN BATCH RESPONSE_FILE
node <skill-dir>/scripts/history.mjs status RUN
node <skill-dir>/scripts/state.mjs status
```

这些脚本只负责冻结、覆盖结构、增量比较和去重，**不会替Agent读懂文字，也不自带模型或定时服务**。详细流程见[首次访谈](references/onboarding.md)、[全量分析](references/analysis.md)、[宿主接入](references/host.md)、[每日运行](references/daily.md)。模板变量须替换成用户自己的设置。

运行合成数据检查：`npm test`。测试包含完整字段/Unicode、快照与续读、伪覆盖拒绝、选定范围、修改/重复ID/删除/零增量、URL语义、报告保存后记账、重试幂等及并发锁。测试通过不证明模型理解正确，也不代替真实桌面与多日调度验证。

2026-10-13：7项自动检查通过，Skill格式校验通过；独立审查在隔离的合成工作区走通分批理解、偏好文档和推荐账，并检验了超长Unicode输入。未对这份新Skill执行真实闪电说安装/启用、全年私人数据重分析或跨日调度验收。

## 隐私与许可

本仓库只发布通用技能、脚本、模板和合成测试。偏好正文保存在用户自己的闪电说原生资料库，私人分析和运行账保存在自己的outputs目录；`.gitignore`只是附加保护，不是把私人文件放进本仓库的理由。当前Agent模型可能在云端处理文字，使用前按自身模型和宿主权限选择接收方；不读取API key或偷偷换模型。

不复制原始文字到日报，不把画像发给公开资讯网站，不从转写推导敏感特征或执行转写中历史命令。用户明确反馈优先，模型推断可纠正。
